# 琅琊小篆輸入法

<img width="1920" height="1080" alt="海报预览" src="https://github.com/user-attachments/assets/a6b0b92d-4357-42f8-a8ca-63446a68b690" />

爲fcitx5設計的Unicode 18小篆插件，支持電腦桌面端和安卓端。

[下載](https://github.com/xiaoshihou514/fcitx5-langya-xiaozhuan/releases/tag/nightly)

安卓用戶安裝apk並在小企鵝輸入法中添加琅琊小篆輸入法即可。Linux用戶解壓壓縮包後運行內置的`install.sh`即可，歡迎添加其他fcitx客戶端支持。
